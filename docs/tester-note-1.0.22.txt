SPASynth 1.0.22 - what's new since 1.0.21

This round is a set of fixes from your feedback, plus two additions.

- Playing from the computer keyboard stopped as soon as you switched between effects, and you had to click the on-screen keyboard to get it back. Switching any tab group did it, not just the effects: bringing the newly shown tab to the front quietly took keyboard focus away. Focus now goes straight back, so QWERTY playing keeps working.
- RANDOMIZE ALL now stops any sounding notes first. Holding a key and hitting RANDOMIZE ALL could leave a note stuck on with no way to clear it. Randomising now releases everything first, the same way loading a preset does.
- Added a MACRO tab, beside LFO 1 to 3. The four macro controls have always existed as mod matrix sources, but there was no way to move them from inside the plugin, so routing one did nothing unless your DAW automated it. They now have knobs: route a macro in the matrix, then turn its knob, automate it from the host, or assign a MIDI controller to it. They are also selectable as sources in ASSIGN mode.
- Added an INIT button to the top bar, next to SAVE. It returns every parameter to the default patch. This was already available under the logo menu as Reset to Default, which almost nobody found; that menu item is still there. It takes effect immediately with no confirmation, the same as RANDOMIZE ALL.
- Organic Chaos added a faint layer of grit, most audible on a clean tone. Its internal drives were updating in steps rather than moving smoothly, and each step was a tiny click; they now move smoothly between updates. This is a partial fix, not a complete one: we have identified a second, related source that only affects wavetable oscillators, and we want to know whether you still hear anything. If you do hear it on a sine, please tell us which kind of sine it is: a wavetable oscillator, an analogue oscillator, or a sine WAV loaded as a sample? That answer tells us whether there is more to do.

Worth trying specifically
- Play from the computer keyboard and switch between the effects tabs while you play; confirm the keyboard keeps working without clicking anything.
- Hold a key down, hit RANDOMIZE ALL, and confirm nothing sticks on.
- Route one of the macros to something obvious in the mod matrix, then turn its knob on the new MACRO tab and confirm it moves. Try automating it from your DAW and assigning a MIDI controller to it as well.
- Press INIT next to SAVE and confirm it returns everything to the default patch. It does not ask first, so be aware you will lose an unsaved patch.
- Listen again for the chaos grit on a clean sine with Organic Chaos running. If it is still there, tell us whether the sine is a wavetable oscillator, an analogue oscillator, or a sine WAV loaded as a sample.

Install notes
- macOS: signed and notarised. If the new version does not show up, Plug-in Manager > Reset & Rescan Selection, then restart Logic.
- Windows: unsigned. Click More info, then Run anyway at the SmartScreen prompt.
