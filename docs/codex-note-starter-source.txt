SPASynth Standard's starter library is now distributed two ways:
- Shopify: the Standard product has a Digital Downloads External URL asset
  (a Dropbox shared link). SPAStation's Shopify-stream path cannot follow
  Dropbox external links.
- For SPAStation, use the R2 copy instead:
  https://downloads.spasynth.com/starter-library/SPASynth-Starter-Library.zip
  size 3641410447 bytes, md5 0df041aed5ed66d7ab7cb759d6719f04
  (sha256: compute on ingest; the file is byte-identical to the Dropbox one)
